Frequently Asked Questions

Everything you need to know about PatchPulse

How does PatchPulse work? ▼
PatchPulse analyzes your Kubernetes deployment changes before they reach production. When you create a PR or MR, our Git integration fetches the diff, our AI evaluates it against guardrails, and we provide a risk score with explainable evidence. You can run in advisory mode (log only) or enforce mode (block risky changes).
What guardrails are included? ▼
PatchPulse includes 6 production-ready guardrails: missing resource limits, disabled HPA, high CPU usage, excessive pod restarts, critical service modifications, and latest image tags. You can also create custom guardrails using our policy engine.
How accurate is the risk scoring? ▼
Our risk scoring is deterministic and based on weighted guardrail severities plus modifiers for critical namespaces. Every decision includes concrete evidence - the exact diff hunks and cluster signals that triggered each guardrail. This transparency helps teams understand and trust the system.
Does it work with my existing CI/CD? ▼
Yes! PatchPulse integrates seamlessly with GitHub, GitLab, and can be integrated into any CI/CD pipeline. We support webhooks and API calls, so you can trigger risk analysis at any stage of your deployment process.
What's the performance impact? ▼
PatchPulse is designed to be lightweight and fast. The agent runs as a single pod in your cluster with minimal resource requirements. Risk analysis typically completes in under 5 seconds. The agent uses read-only Kubernetes API access, so there's no impact on your cluster performance.
Can I customize the guardrails? ▼
Absolutely! PatchPulse uses a registry-based policy engine that makes it easy to add custom guardrails. You can write guardrails in Python that analyze diffs and cluster signals, then register them with the system. Since it's open source, you have full access to customize everything.
Is there a free tier? ▼
Yes! PatchPulse is 100% open source and free. You can self-host it on your infrastructure with all features included. You'll need to provide your own AI API key (OpenAI, DeepSeek, Claude, or Gemini) for AI-powered analysis.
How do I get started? ▼
Getting started is easy! You can deploy PatchPulse to your Kubernetes cluster using our Helm charts, or run it locally with Docker Compose. The setup takes about 10 minutes. Check out our quickstart guide or try the interactive demo to see it in action.

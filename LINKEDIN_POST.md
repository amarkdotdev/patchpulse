## Post Content

🚀 **Announcing PatchPulse: Open Source Kubernetes Risk Analysis Platform**

I'm excited to announce the launch of **PatchPulse** - a 100% open-source, self-hosted platform that prevents production incidents by analyzing Kubernetes changes before deployment.

**🔓 Fully Open Source (MIT License)**
- Complete transparency - audit every line of code
- No vendor lock-in - self-host everything
- Community-driven development

**🤖 Bring Your Own LLM**
- Use OpenAI, DeepSeek, Claude, Gemini, or any OpenAI-compatible API
- Support for local LLMs (Ollama, LocalAI, vLLM)
- Works perfectly without any LLM - rule-based guardrails still function

**🛡️ Enterprise-Grade Features**
- 11+ Kubernetes guardrails (resource limits, security contexts, HPA, etc.)
- AI-powered security scanning & recommendations
- Admission webhook for Kubernetes-native enforcement
- Policy-as-Code with versioned bundles
- SBOM verification & supply chain security
- Multi-tenancy & RBAC support
- Real-time risk scoring (0-100)
- Incident prediction & cost optimization

**⚡ Key Capabilities**
- Pre-flight risk analysis for all K8s changes
- Real-time cluster signal correlation
- GitHub/GitLab integration
- Slack/Teams/PagerDuty notifications
- Comprehensive audit logging
- Beautiful dashboard with analytics

**🚀 Quick Start**
```bash
git clone https://github.com/amarkdotdev/patchpulse.git
cd patchpulse
docker compose up -d
```

**Perfect for:**
- SRE teams preventing production incidents
- DevOps engineers enforcing best practices
- Security teams ensuring compliance
- Platform teams building internal tooling

**100% Free & Open Source** - No SaaS, no subscriptions, no limits. Your data stays on your infrastructure.
